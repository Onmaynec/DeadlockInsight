# DeadlockInsight — план разработки

## 0.1.x — фундамент

- минимальный Panorama loader без копирования всего HUD;
- единое состояние матча;
- безопасный DataProvider;
- отображение нейтральных кемпов на миникарте;
- таймер после подтверждённого перехода кемпа из active в inactive;
- objective bar;
- каркас Smart Shop;
- движок ранжирования предметов с объяснимыми причинами.

## 0.2.x — реальные игровые данные магазина

- определить стабильные панели/события для:
  - собственного героя;
  - своих предметов;
  - видимых предметов противников;
  - душ;
  - сопротивлений;
  - текущего lane context;
- подключить актуальный каталог предметов;
- добавить теги предметов и контр-связи;
- первые реальные рекомендации вместо пустого состояния.

## 0.3.x — анализ состава

- профиль урона команды противника;
- CC / healing / burst / sustain / mobility;
- роль и направление билда игрока;
- синергия с союзником на линии;
- отдельные причины: LANE / COUNTER / TEAM / ECONOMY.

## 0.4.x — карта и objectives

- world markers для ближайших объектов;
- Sinner's Sacrifice;
- Powerup spawn states;
- Mid Boss через подтверждённый штатный источник;
- confidence indicator: confirmed / estimated / unknown;
- настройки плотности миникарты.

## 0.5.x — полноценный Smart Shop

- динамическая переоценка рекомендаций;
- реакция на видимые покупки противников;
- защита от дублирования utility внутри команды;
- power spike и budget analysis;
- explanation tooltip для каждого предложения.

## Правило источников данных

DeadlockInsight не должен получать преимущество за счёт скрытого состояния матча.

Разрешённые источники:

- данные, уже показанные штатным HUD;
- состояния штатных Panorama panels;
- подтверждённые клиентские события;
- расчёты из публичных таймингов.

Запрещённый подход проекта:

- чтение памяти процесса ради скрытых данных;
- ESP;
- раскрытие противника/кемпа через fog, если штатный клиент это не показывает;
- автоматические игровые действия.
