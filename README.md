# DeadlockInsight

DeadlockInsight — крупный HUD/QoL-мод для Deadlock с упором на карту, objectives и контекстные рекомендации в магазине.

Проект не должен раскрывать скрытую информацию через fog и не должен выполнять игровые действия за игрока. Анализ строится на данных, которые уже доступны штатному клиентскому интерфейсу, и на прозрачных расчётах таймингов.

## Что уже заложено

Текущая ветка разработки: `dev/0.1.0-foundation`.

- минимальный Panorama HUD loader;
- единое состояние матча;
- отдельный слой получения игровых данных;
- трекер нейтральных кемпов;
- компактные отметки кемпов на миникарте;
- таймер респавна после подтверждённого изменения состояния;
- базовый objective bar;
- каркас Smart Shop;
- движок оценки предметов с объяснимыми причинами;
- состояния достоверности `confirmed / estimated / unknown`.

Визуал пока временный. Финальные иконки, рамки, бейджи и world markers будут подключены отдельным asset pack.

## В разработке

Ближайшая задача — получить стабильные данные из штатного HUD для героя, собственных предметов, видимых предметов противников, душ, сопротивлений и lane context. После этого Smart Shop начнёт выдавать реальные динамические рекомендации вместо пустого состояния.

Подробный план: [docs/ROADMAP.md](docs/ROADMAP.md)

Список ожидаемых графических ассетов: [docs/ASSETS.md](docs/ASSETS.md)

## Установка

Готовой публичной VPK-сборки пока нет. Репозиторий находится на ранней стадии разработки.

Релизные версии будут публиковаться отдельно после проверки в игре и настройки стабильной сборки VPK.
